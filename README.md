# Портфолио графического дизайнера

Сайт-портфолио бренд- и коммуникационного дизайнера.

## Ссылка

https://vaoaoadim.github.io/olesya-usova-portfolio/

## О проекте

Портфолио объединяет учебные концепты, коммерческие проекты и резюме дизайнера. Главная ведёт к отдельным страницам кейсов, где описаны задачи, решения и результаты.

## Возможности

- Русская и английская версии с прямыми ссылками на кейсы.
- Интерактивная галерея работ с навигацией для мыши, клавиатуры и сенсорных экранов.
- Светлая и тёмная темы с отдельными видео на первом экране.
- Резюме и скачивание CV на языке сайта.

## Технологии

- Astro
- TypeScript / JavaScript
- HTML5 / CSS3
- GitHub Pages
